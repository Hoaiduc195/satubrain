# Roadmap

## Stable v1.0 release gates

- [ ] Verify installation and CI on Linux, Windows and macOS.
- [ ] Test real handoffs across Claude Code, Codex, Copilot and Cursor.
- [ ] Verify encrypted sync on two physical devices.
- [ ] Audit tracked files and Git history for secrets; review demo assets.
- [ ] Publish a verified package and release notes.

## Adoption improvements

- Safe, opt-in setup wizard with configuration preview, backup and rollback.
- Dynamic task selection without restarting clients where supported.
- Reproducible cross-agent walkthrough and troubleshooting examples.
- Measure context savings against a documented baseline before making token-saving claims.

The core remains local-first, with no mandatory accounts, telemetry or paid APIs. Roadmap items are proposals, not shipped features.
